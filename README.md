# PhCraft Ban Archive

PhCraft 严重违规案件档案，供玩家、服务器管理员和联 Ban 系统查阅。

## 案件

| 编号 | 玩家 | 事件日期 | 违规类型 | 本服处罚 |

每个案件包含经过、处罚、证据和文件校验值。程序可读取案件目录中的 `case.json`，字段见 [Schema](schemas/case.schema.json)。

## 收录与更正

仅收录经管理员核实、需要长期留档的严重违规。玩家身份以 Minecraft UUID 为准。

- `confirmed`：案件结论有效。
- `overturned`：复核后撤销原结论。

更正会保留记录。联 Ban 系统应跟进状态变化，其他服务器自行决定是否处罚。

申诉或事实更正请[创建 Issue](https://github.com/PhCraft-Team/PhCraft-BanArchive/issues/new/choose)，注明案件编号、争议内容及依据。不要在公开 Issue 中提交联系方式、IP 或账号凭据。

## 证据与使用

公开材料已脱敏，私人基地坐标按需隐藏。完整原件由管理员保存，文件校验值用于检查公开副本是否变化。

允许查阅、链接和按条款读取案件数据；未经许可，不得转载证据或镜像仓库。详见 [LICENSE](LICENSE)。

管理员发布要求见 [POLICY.md](POLICY.md)，新案件使用 [案件模板](templates/case/)。
